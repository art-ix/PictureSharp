# PictureSharp 0.8.4

This release reduces the size of the NuGet packages.

- **Smaller package icon.** The packages now include a 128×128 icon (12 KB), the size NuGet displays, instead of the 1254×1254 original (592 KB) added in 0.8.3. PictureSharp shrinks from 1.09 MB to 0.63 MB, and PictureSharp.Drawing, PictureSharp.Skia and PictureSharp.AspNetCore from about 0.49 MB to 26–35 KB.

No API, dependency or image-processing changes since 0.8.3.
