# PictureSharp 0.8.3

This release adds the PictureSharp project icon and updates the README presentation.

- **NuGet package icon.** PictureSharp, PictureSharp.Drawing, PictureSharp.Skia and PictureSharp.AspNetCore now include the project icon.
- **README banner.** A banner with the project logo, name and description replaces the small icon. A separate 1280×640 image is available for GitHub social previews.

No API, dependency or image-processing changes since 0.8.2.
